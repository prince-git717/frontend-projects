# Animated Product Designer Website

A modern animated website inspired by premium designer-style landing pages.
This project focuses on smooth scrolling, interactive hover effects, GSAP animations, custom cursor interactions, and responsive design using modern frontend technologies.

## Features

* Smooth scrolling using Locomotive Scroll
* GSAP timeline entrance animations
* Interactive image hover effects
* Custom animated cursor
* Fully responsive layout
* Modern dark-themed UI
* Animated navigation and text transitions
* Mouse-following image interactions

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GSAP
* Locomotive Scroll
* Remix Icons

## Sections Included

* Hero Section
* Animated Headings
* Interactive Work Showcase
* About Section
* Responsive Mobile Layout

## Animations Included

* Text reveal animations
* Hover image preview effects
* Mouse-follow cursor
* Smooth scroll transitions
* Fade and translate effects using GSAP timelines

## Purpose of the Project

This project was built to practice:

* Advanced CSS layouts
* GSAP animations
* Smooth scrolling effects
* Interactive UI design
* Responsive web development

## Run Locally

1. Clone the repository
2. Open the project folder
3. Run the `index.html` file using Live Server
